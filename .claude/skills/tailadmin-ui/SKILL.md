# Procedimiento

Consultar el OpenSpec 11 y los componentes existentes. Usar sidebar marino, fondo suave, tarjetas blancas, tablas compactas con búsqueda/filtros/paginación, estados de carga y vacío, accesibilidad y diseño móvil. Reutilizar tokens/componentes; evitar HTML visual inventado y estilos por módulo.
