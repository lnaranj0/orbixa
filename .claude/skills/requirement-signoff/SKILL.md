# Procedimiento

Consultar OpenSpec 10; separar solicitud de work item; capturar solicitante real, fecha y área; versionar el contenido aprobado; identificar hash/documento firmado, tipo de evidencia y aprobador; los cambios posteriores generan nueva versión y nueva aprobación. Evitar afirmar validez legal de un mecanismo no evaluado.
